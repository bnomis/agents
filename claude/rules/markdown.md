# Markdown rules

Use plain ASCII punctuation. Avoid characters that signal copy-paste
from a word processor or LLM output:

- Use `-` (hyphen), not `—` (em-dash) or `–` (en-dash).
- Use `"` and `'`, not `""`, `''`, `"`, or `'`.
- Use `...` (three dots), not `…`.

These rules apply to `.md` files. Apply the same conventions in chat
responses and commit messages too.
